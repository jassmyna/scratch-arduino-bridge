# Media

This directory contains visual materials documenting the Scratch-Arduino Bridge and its use in an interactive STEM workshop.

## Planned Materials

- `hardware-setup.jpg` — Arduino and wiring setup
- `scratch-game.png` — Scratch game interface
- `workshop-demo.jpg` — Workshop activity
- `demo.gif` — Short demonstration of the game and hardware interaction

Add only original photographs, screenshots, or recordings that you have permission to share. Avoid including children's identifiable faces without appropriate permission.

## Purpose

These materials will demonstrate the physical setup, Scratch interface, and practical use of the bridge in an educational setting.
