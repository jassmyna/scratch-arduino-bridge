## Workshop Demonstration: Interactive Arduino Game

Developed and demonstrated an interactive game for children during a STEM workshop, using Scratch and an Arduino Mega connected through a custom Python bridge.

The initial activity challenged participants to connect a cable to a specified Arduino pin as quickly as possible. Throughout the workshop, I iteratively improved the Scratch code, refining the game while keeping the underlying Python bridge and Arduino firmware unchanged.

### Technologies
- Scratch
- Python
- Arduino Mega
- Serial communication
- Scratch cloud variables

### Learning Context
The project introduced children to physical computing through a hands-on activity, connecting visual programming with real hardware inputs and immediate feedback.
